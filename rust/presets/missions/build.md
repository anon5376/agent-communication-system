# build
Add a feature or make a change.

## brief
Build this: {goal}

1. Read the code that the change touches and how the project builds and tests.
2. Make the smallest change that delivers it, in the existing style.
3. Add or update a test when the project has tests.
4. Have the reviewer check the change before you submit the goal.

## acceptance
- The feature works, shown by a test or a command and its output.
- The project's existing tests and build still pass, or the result says which fail and why.
- The result lists the files changed.
