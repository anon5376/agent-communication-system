# Security policy

Report a vulnerability through [GitHub Security Advisories](https://github.com/anon5376/agent-communication-system/security/advisories/new). Include the affected version or commit, the impact, reproduction steps, and a minimal proof of concept. Do not place secrets or personal data in the report unless they are essential to reproduction.

The project does not publish a private security email address. Public issues are appropriate for non-sensitive hardening ideas only.

The supported security model and its limits are documented in [docs/security.md](docs/security.md).
